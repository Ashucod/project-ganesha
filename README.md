# 🪔 Virtual Aarti Experience | Ganesh Chaturthi

An interactive, immersive web experience of our beloved ganpati bappa. 

This project allows users to partake in a digital Aarti, spatial audio, and interactive elements, all built without external frameworks.

# ✨ Features:
**Interactive Temple Bell:** Click the hanging brass bell to play a crisp ringing audio clip.
**Dynamic Cursor Follower:** During Aarti mode, an Aarti Thali smoothly tracks the user's mouse movements across the screen in real-time using Vanilla JavaScript event listeners.
**Audio Integration:** Features seamless background Aarti music that syncs with the visual state of the application.

# 🛠️ Tech Stack :
- HTML5
- CSS3
- Vanilla JavaScript
